# Gradient Boosting in a Location-Scale Regression Framework

Academic term paper in group for the course *Advanced Statistical Programming with R* (Georg-August-Universität Göttingen).

### Summary
Implementation of the `lmls.boosting` R package for Gaussian location-scale models, featuring cyclic and non-cyclic gradient boosting, linear and B-spline base learners, early stopping via cross-validation, and an extensive ADEMP simulation study.
